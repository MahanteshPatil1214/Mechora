# MECHORA Evaluation

Deterministic rule-based evaluation against a **frozen synthetic set** of 216
record narratives in `data/evaluation/eval_set.json`.

> Ground truth is generated by the same deterministic rules the engine is
> evaluated on (`scripts/generate_dataset.py`), keeping GT and engine aligned.
> This measures pipeline determinism and coverage, not field accuracy vs human
> judgement — a separate labeled-set exercise is out of MVP scope.

## How to run

```powershell
cd E:\Mecora
.\.venv\Scripts\python scripts\run_evaluation.py
```

Writes per-run metrics to `data/evaluation/results/latest.json` (served by
`GET /api/v1/evaluation/latest`).

Backend acceptance suite (fast, includes the frozen-record targets):

```powershell
cd E:\Mecora\backend
..\.venv\Scripts\python -m pytest -q
```

## Metrics per record

Each record is scored per field (`activity`, `task_phase`, `energy`,
`barrier`, `barrier_state`, `exposure`, `potential_consequence`,
`location`), plus derived outputs:

- **sif** — exact classification match and macro-F1 over classes.
- **lsr** — exact life-saving-rule set match.
- **family tag** — whether the observation landed in the expected structural
  family id.
- **schema_valid** — the extracted event passed the strict schema.
